# S05 — Exploiter les biais du marché (favoris, outsiders, nuls, domicile)

> Statut : ⚠️ **biais réels mais aucun n'est rentable joué seul**. Leur vraie utilité :
> savoir **quoi éviter**.

## Biais favori/outsider (FLB)

Les outsiders sont surpayés par le public, donc mal payés par les cotes. ROI en pariant
systématiquement toutes les issues d'une tranche :

| Sport (période test) | Gros favoris (cote < 1,3) | Gros outsiders (cote > 4) |
|---|---|---|
| Tennis ATP | −0,6 % | −14,8 % |
| Tennis WTA | −0,4 % | −19,5 % |
| NFL | −1,8 % | −13,6 % |
| UFC | +2,1 % (IC −0,9/+5,1) | −38,9 % |
| Football (cote > 10, 2012-2026) | — | −15 % à −37 % |

## Football : domicile, nul, extérieur (tous les matchs, 2012-2026)

| Cotes | Domicile | Nul | Extérieur |
|---|---|---|---|
| Moyenne | −6,3 % | −7,3 % | −10,1 % |
| Pinnacle clôture | −3,4 % | −3,4 % | −5,2 % |
| Meilleure cote | −1,5 % | −1,4 % | −3,1 % |

Pas de « biais du nul » exploitable, ni de biais domicile : les pertes suivent la marge.
Les victoires à l'extérieur, plus souvent outsiders, perdent davantage (FLB).

## Règles pratiques qui en découlent

1. **Éviter les cotes > 4-5** (et les combinés d'outsiders) : c'est là que la marge
   réelle est la plus forte.
2. Les gros favoris sont proches de l'équilibre : ils perdent peu, mais ne gagnent pas.
3. Les combinés multiplient les marges : un combiné de 4 matchs à 7 % de marge chacun
   coûte environ 25 % d'espérance.

Littérature : Forrest & Simmons, Cain, Law & Peel, Štrumbelj, Winkelmann et al. (2024),
Vandenbruaene et al. (2022) — les biais publiés disparaissent souvent hors échantillon.
